# Renfo marathon

Fiche mobile des 9 exercices de renfo de la prépa marathon du 14 mars 2027 : illustration, consignes, répétitions par niveau et chrono pour les gainages.

En ligne : https://lucaszimmermann.github.io/renfo-marathon/

- `?niveau=1`, `2` ou `3` force le niveau, sinon il est choisi selon la date (niveau 2 dès le 14/12, niveau 3 dès le 18/01).
- Les exercices et les illustrations sont dans `build.py`, la mise en page dans `template.html`.
- Après une modification : `python3 build.py` régénère `index.html`, puis commit et push.
